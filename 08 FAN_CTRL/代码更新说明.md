# 08 FAN_CTRL 工程代码更新说明

## 更新内容

本次更新将 08 FAN_CTRL 工程中的风扇控制代码进行了模块化改造，参考 Simu_STM32F407_UDP_FAN_Temp 工程的设计模式。

## 新增文件

### 1. Inc/fanctrl.h
- 定义了风扇控制相关的结构体和函数声明
- 包含 FAN_INFO、CURVE_SECTION_PARAM、CURVE_PARAM、FAN_GROUP 等结构体
- 声明了风扇控制函数接口

### 2. Src/fanctrl.c
- 实现了风扇控制的核心逻辑
- 包含以下功能函数：
  - `fanctrl_init()`：初始化风扇控制
  - `fan_pwm_auto_set()`：风扇自动控制（预留接口）
  - `update_fanctl_offset()`：更新风扇转速偏移量
  - `fan_pwm_set_single()`：控制单个风扇转速
  - `fan_enter_dbg_mode()`：进入调试模式
  - `fan_exit_dbg_mode()`：退出调试模式
  - `fan_pwm_set_all()`：设置所有风扇转速

## 修改文件

### 1. Src/main.c
- 添加了 `#include "fanctrl.h"` 头文件引用
- 移除了原来的 `PWM_SetDutyPercent_ById()` 函数定义
- 将风扇初始化代码替换为 `fanctrl_init()` 调用
- 将所有 `PWM_SetDutyPercent_ById()` 调用替换为 `fan_pwm_set_single()` 调用

### 2. MDK-ARM/EdgeMCU_test.uvprojx
- 在工程配置中添加了 fanctrl.c 文件的引用

## 改进优势

1. **代码结构更清晰**：风扇控制逻辑从 main.c 中分离，单独放在 fanctrl.c 中
2. **接口更规范**：提供了标准化的函数接口
3. **可扩展性更好**：预留了温度自动控制接口
4. **便于维护**：模块化设计便于后续功能扩展和bug修复

## 使用方法

### 初始化风扇控制
```c
fanctrl_init();  // 在 main() 函数中调用
```

### 控制单个风扇
```c
fan_pwm_set_single(50, 0);  // 设置风扇0的占空比为50%
```

### 控制所有风扇
```c
fan_pwm_set_all(50);  // 设置所有风扇的占空比为50%
```

### 调试模式
```c
fan_enter_dbg_mode();  // 进入调试模式，关闭自动控制
fan_exit_dbg_mode();   // 退出调试模式，开启自动控制
```
