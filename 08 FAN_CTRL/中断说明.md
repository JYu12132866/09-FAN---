# STM32F103 SPI2中断原理与实现方式详解

## 一、概述

本文档以SPI2中断初始化代码为起点，层层深入解析STM32F103中断系统的原理和实现方式。

### 起始代码位置
文件：`Src/spi.c` 第120-121行
```c
/* SPI2 interrupt Init */
HAL_NVIC_SetPriority(SPI2_IRQn, 1, 0);
HAL_NVIC_EnableIRQ(SPI2_IRQn);
```

## 三、第一层：HAL_NVIC_SetPriority() 函数详解

### 3.1 函数声明位置
文件：`Drivers/STM32F1xx_HAL_Driver/Inc/stm32f1xx_hal_cortex.h` 第262行
```c
void HAL_NVIC_SetPriority(IRQn_Type IRQn, uint32_t PreemptPriority, uint32_t SubPriority);
```

### 3.2 函数定义位置
文件：`Drivers/STM32F1xx_HAL_Driver/Src/stm32f1xx_hal_cortex.c` 第164-179行

```c
/**
  * @brief  Sets the priority of an interrupt.
  * @param  IRQn: External interrupt number.
  *         This parameter can be an enumerator of IRQn_Type enumeration
  *         (For the complete STM32 Devices IRQ Channels list, please refer 
  *          to the appropriate CMSIS device file (stm32f10xx.h))
  * @param  PreemptPriority: The preemption priority for the IRQn channel.
  *         This parameter can be a value between 0 and 15
  *         A lower priority value indicates a higher priority 
  * @param  SubPriority: the subpriority level for the IRQ channel.
  *         This parameter can be a value between 0 and 15
  *         A lower priority value indicates a higher priority.          
  * @retval None
  */
void HAL_NVIC_SetPriority(IRQn_Type IRQn, uint32_t PreemptPriority, uint32_t SubPriority)
{ 
  uint32_t prioritygroup = 0x00U;
  
  /* Check the parameters */
  assert_param(IS_NVIC_SUB_PRIORITY(SubPriority));
  assert_param(IS_NVIC_PREEMPTION_PRIORITY(PreemptPriority));
  
  prioritygroup = NVIC_GetPriorityGrouping();
  
  NVIC_SetPriority(IRQn, NVIC_EncodePriority(prioritygroup, PreemptPriority, SubPriority));
}
```

### 3.3 逐行解释

| 代码行 | 含义 |
|--------|------|
| `void HAL_NVIC_SetPriority(IRQn_Type IRQn, uint32_t PreemptPriority, uint32_t SubPriority)` | 函数声明，接收三个参数：中断号、抢占优先级、子优先级 |
| `uint32_t prioritygroup = 0x00U;` | 定义局部变量，用于存储当前优先级分组配置 |
| `assert_param(IS_NVIC_SUB_PRIORITY(SubPriority));` | 参数检查，确保子优先级在有效范围内(0-15) |
| `assert_param(IS_NVIC_PREEMPTION_PRIORITY(PreemptPriority));` | 参数检查，确保抢占优先级在有效范围内(0-15) |
| `prioritygroup = NVIC_GetPriorityGrouping();` | 获取当前NVIC优先级分组设置 |
| `NVIC_SetPriority(IRQn, NVIC_EncodePriority(prioritygroup, PreemptPriority, SubPriority));` | 编码优先级并设置到NVIC寄存器 |

### 3.4 参数详解

#### IRQn_Type IRQn
- **类型**：枚举类型
- **定义位置**：`Drivers/CMSIS/Device/ST/STM32F1xx/Include/stm32f103xe.h` 第118行
- **SPI2_IRQn的值**：36

```c
typedef enum
{
  // ... 其他中断号 ...
  SPI2_IRQn                   = 36,     /*!< SPI2 global Interrupt */
  // ... 其他中断号 ...
} IRQn_Type;
```

#### PreemptPriority (抢占优先级)
- **取值范围**：0-15
- **含义**：数值越小，优先级越高
- **作用**：高抢占优先级可以打断低抢占优先级的中断

#### SubPriority (子优先级)
- **取值范围**：0-15
- **含义**：数值越小，优先级越高
- **作用**：当抢占优先级相同时，子优先级决定执行顺序

## 四、第二层：NVIC_SetPriority() 函数详解

### 4.1 宏定义映射
文件：`Drivers/CMSIS/Include/core_cm3.h` 第1447行
```c
#define NVIC_SetPriority            __NVIC_SetPriority
```

### 4.2 实际函数定义
文件：`Drivers/CMSIS/Include/core_cm3.h` 第1639-1649行

```c
/**
  \brief   Set Interrupt Priority
  \details Sets the priority of a device specific interrupt or a processor exception.
           The interrupt number can be positive to specify a device specific interrupt,
           or negative to specify a processor exception.
  \param [in]      IRQn  Interrupt number.
  \param [in]  priority  Priority to set.
  \note    The priority cannot be set for every processor exception.
  */
__STATIC_INLINE void __NVIC_SetPriority(IRQn_Type IRQn, uint32_t priority)
{
  if ((int32_t)(IRQn) >= 0)
  {
    NVIC->IP[((uint32_t)IRQn)] = (uint8_t)((priority << (8U - __NVIC_PRIO_BITS)) & (uint32_t)0xFFUL);
  }
  else
  {
    SCB->SHP[(((uint32_t)IRQn) & 0xFUL)-4UL] = (uint8_t)((priority << (8U - __NVIC_PRIO_BITS)) & (uint32_t)0xFFUL);
  }
}
```

### 4.3 逐行解释

| 代码行 | 含义 |
|--------|------|
| `__STATIC_INLINE` | 编译器关键字，表示静态内联函数 |
| `void __NVIC_SetPriority(IRQn_Type IRQn, uint32_t priority)` | 函数声明，接收中断号和优先级值 |
| `if ((int32_t)(IRQn) >= 0)` | 判断是外设中断(>=0)还是内核异常(<0) |
| `NVIC->IP[((uint32_t)IRQn)]` | 访问NVIC的IP寄存器数组，索引为中断号 |
| `(uint8_t)((priority << (8U - __NVIC_PRIO_BITS)) & (uint32_t)0xFFUL)` | 将优先级值左移并截取8位 |
| `SCB->SHP[...]` | 内核异常优先级设置（本例不涉及） |

### 4.4 NVIC寄存器结构体
文件：`Drivers/CMSIS/Include/core_cm3.h` 第340-355行

```c
typedef struct
{
  __IOM uint32_t ISER[8U];               /*!< Offset: 0x000 (R/W)  Interrupt Set Enable Register */
        uint32_t RESERVED0[24U];
  __IOM uint32_t ICER[8U];               /*!< Offset: 0x080 (R/W)  Interrupt Clear Enable Register */
        uint32_t RSERVED1[24U];
  __IOM uint32_t ISPR[8U];               /*!< Offset: 0x100 (R/W)  Interrupt Set Pending Register */
        uint32_t RESERVED2[24U];
  __IOM uint32_t ICPR[8U];               /*!< Offset: 0x180 (R/W)  Interrupt Clear Pending Register */
        uint32_t RESERVED3[24U];
  __IOM uint32_t IABR[8U];               /*!< Offset: 0x200 (R/W)  Interrupt Active bit Register */
        uint32_t RESERVED4[56U];
  __IOM uint8_t  IP[240U];               /*!< Offset: 0x300 (R/W)  Interrupt Priority Register (8Bit wide) */
        uint32_t RESERVED5[644U];
  __OM  uint32_t STIR;                   /*!< Offset: 0xE00 ( /W)  Software Trigger Interrupt Register */
} NVIC_Type;
```

## 六、第四层：NVIC_EnableIRQ() 函数详解

### 6.1 宏定义映射
文件：`Drivers/CMSIS/Include/core_cm3.h` 第1440行
```c
#define NVIC_EnableIRQ              __NVIC_EnableIRQ
```

### 6.2 实际函数定义
文件：`Drivers/CMSIS/Include/core_cm3.h` 第1511-1517行

```c
/**
  \brief   Enable Interrupt
  \details Enables a device specific interrupt in the NVIC interrupt controller.
  \param [in]      IRQn  Device specific interrupt number.
  \note    IRQn must not be negative.
  */
__STATIC_INLINE void __NVIC_EnableIRQ(IRQn_Type IRQn)
{
  if ((int32_t)(IRQn) >= 0)
  {
    NVIC->ISER[(((uint32_t)IRQn) >> 5UL)] = (uint32_t)(1UL << (((uint32_t)IRQn) & 0x1FUL));
  }
}
```

### 6.3 逐行解释

| 代码行 | 含义 |
|--------|------|
| `__STATIC_INLINE void __NVIC_EnableIRQ(IRQn_Type IRQn)` | 静态内联函数，接收中断号 |
| `if ((int32_t)(IRQn) >= 0)` | 确保是外设中断（非内核异常） |
| `NVIC->ISER[(((uint32_t)IRQn) >> 5UL)]` | 计算ISER寄存器索引：IRQn / 32 |
| `(uint32_t)(1UL << (((uint32_t)IRQn) & 0x1FUL))` | 计算位掩码：1 << (IRQn % 32) |

### 6.4 SPI2中断使能计算示例

对于SPI2_IRQn = 36：
- ISER索引：36 >> 5 = 1（即ISER[1]）
- 位位置：36 & 0x1F = 4（即第4位）
- 最终操作：`NVIC->ISER[1] = (1 << 4)`

## 八、中断优先级分组

### 8.1 优先级分组设置
文件：`Drivers/STM32F1xx_HAL_Driver/Src/stm32f1xx_hal.c` 第157行

```c
HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_4);
```

### 8.2 NVIC_PRIORITYGROUP_4 含义
文件：`Drivers/STM32F1xx_HAL_Driver/Inc/stm32f1xx_hal_cortex.h`

```c
#define NVIC_PRIORITYGROUP_4  0x00000070U  /*!< 4 bits for preemption priority
                                              0 bits for subpriority */
```

### 8.3 优先级分组表

| 分组 | 抢占优先级位数 | 子优先级位数 | 抢占优先级范围 | 子优先级范围 |
|------|---------------|-------------|---------------|-------------|
| NVIC_PRIORITYGROUP_0 | 0 | 4 | 无 | 0-15 |
| NVIC_PRIORITYGROUP_1 | 1 | 3 | 0-1 | 0-7 |
| NVIC_PRIORITYGROUP_2 | 2 | 2 | 0-3 | 0-3 |
| NVIC_PRIORITYGROUP_3 | 3 | 1 | 0-7 | 0-1 |
| NVIC_PRIORITYGROUP_4 | 4 | 0 | 0-15 | 无 |

### 8.4 SPI2优先级解析

对于 `HAL_NVIC_SetPriority(SPI2_IRQn, 1, 0)`：
- 在NVIC_PRIORITYGROUP_4分组下
- 抢占优先级 = 1
- 子优先级 = 0（实际无效）
- 最终优先级值 = 1 << 4 = 16（8位优先级寄存器中的值）

## 九、中断执行流程

```
┌─────────────────────────────────────────────────────────────┐
│ 1. SPI2外设产生中断事件（如接收缓冲区非空RXNE）              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. NVIC检测到中断请求，检查中断是否使能（ISER寄存器）        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. NVIC检查中断优先级，与当前运行中断比较                    │
│    - 如果优先级更高，触发中断嵌套                            │
│    - 如果优先级更低，等待当前中断完成                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. CPU保存当前上下文（寄存器入栈）                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 5. CPU从向量表中查找SPI2_IRQHandler地址                      │
│    向量表偏移 = 16(内核异常) + 36(SPI2_IRQn) = 52           │
│    地址 = 0x08000000 + 52 * 4 = 0x080000D0                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 6. 跳转到SPI2_IRQHandler()执行                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 7. 调用用户定义的SPI2_SlaveIRQHandler()处理中断              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 8. 中断返回，恢复上下文，继续执行原程序                      │
└─────────────────────────────────────────────────────────────┘
```

## 十、关键寄存器总结

## 十三、注意事项

1. **优先级分组必须在系统初始化时设置**，且只能设置一次
2. **优先级数值越小，优先级越高**
3. **中断服务函数名称必须与向量表中的名称一致**
4. **使用NVIC_PRIORITYGROUP_4时，只有抢占优先级有效**
5. **中断处理函数应尽量简短，避免长时间占用CPU**
